## 2. Key `1.10f` -> `1.12a` Engine & Struct Layout Deltas

### 2.1 Ordinal Reshuffling Across All D2 DLLs
Between `1.10f` and `1.12a` (`1.11`–`1.12a`), Blizzard randomized/shuffled the ordinal export tables of `D2Common.dll` (`#10000`–`#11171`), `D2Game.dll` (`#10000`–`#10060`), `D2Win.dll` (`#10000`–`#10206`), `D2Gfx.dll` (`#10000`–`#10082`), `D2CMP.dll` (`#10000`–`#10106`), `D2Sound.dll` (`#10000`–`#10070`), `D2Net.dll` (`#10000`–`#10037`), `D2Lang.dll` (`#10000`–`#10012`), and `D2MCPClient.dll` (`#10000`–`#10062`), while `Fog.dll` inserted ordinal `#10260` (shifting `#10260`–`#10266` to `#10261`–`#10267`).
- Every ordinal in `.1.12a.def` and `D2.Detours.patches/1.12a/` was matched and verified via instruction-level disassembly, import call-site tracing, and cross-TU call graphs.

### 2.2 `D2Common.dll` Reshuffled DRLG & Room Struct Layouts (`1.12a`)

### 2.3 `D2Game.dll` Client-to-Server Packet IDs & `D2ClientStrc` (`1.12a`)
- `D2ClientStrc` (`sizeof = 0x518`): Verified via `Clients_staticchecks.cpp`.
- Client-to-server packet table (`D2Game` `0x6FD26758`, `109` entries `0x00`–`0x6C`):
  - `0x66`: `nullptr` (unused in `1.12a`)
  - `0x67` (`D2GS_GAMELOGON`): `D2GAME_GameLogonReceipt_6FC32360`, size `0x2E` (`46` bytes)
  - `0x68`: `D2GAME_SwitchToLogonState_6FC31F20`
  - `0x69` (`D2GS_LEAVINGGAME`): `D2GAME_LeaveGame_6FC31DF0`
  - `0x6A`: `D2GAME_JoinAct_6FC31DD0`
  - `0x6B` (`D2GS_LOADCOMPLETE`): `D2GAME_LoadComplete_6FC31C50`
  - `0x6C` (`D2GS_ SaveloadFileChunk`): `sub_6FC31DC0`
- Uber Tristram / Pandemonium Event (`D2_VERSION_HAS_UBERS`): Enabled for `1.12a` (`1.11`+ feature set).

### 2.4 `Storm.dll` `TSHashTable` Vtable Order (`1.12a`)
- In `1.12a`, `TSHashTable` places `InternalDelete` (`vtable[0]`) and `InternalNew` (`vtable[1]`) at the start of the vtable rather than the end (matched in `external/squall/include/storm/hash/TSHashTable.hpp` under `D2_VERSION_112A`).

### 2.5 `1.12a` No-CD MPQ Loading (`ARCHIVE_LoadExpansionArchives`)
- Patch `1.12a` introduced official No-CD support when `d2music.mpq` / `d2xmusic.mpq` / `d2video.mpq` / `d2xvideo.mpq` are present in the install directory (`D2WinArchive.cpp`).

## 3. Reconstructed Modules Summary

1. **`source/Storm`** (`Storm.dll`, `361` exports): MPQ archive I/O, PKWare compression, SMem heap/pool allocators, SStr string utilities, SReg registry helpers, SNet/SGdi/SDraw/SEvt/SCode/SBlt/SCmd/SErr subsystems.
2. **`source/Fog`** (`Fog.dll`, `268` exports): Memory pool manager, async file loader (`AsyncData`), `.txt`/`.bin` Excel table compiler and formula AST evaluator (`Calc`), bit stream manipulator (`BitManip`), CRC16/checksum/popcount, error/log/trace manager, `QServer` TCP/IP host, and Winsock wrappers.
3. **`source/D2Common`** (`D2Common.dll`, `1,172` exports): Full `1.12a` ordinal mapping, data tables (`DATATBLS_*`), DRLG dungeon/outdoor/maze/preset generation (`DRLG_*`), units (`UNITS_*`), statlists (`STATLIST_*`), items (`ITEMS_*`), skills (`SKILLS_*`), monsters (`MONSTER_*`), missiles (`MISSILE_*`), collision (`COLLISION_*`), and A*/IDA* pathfinding (`PATH_*`).
4. **`source/D2Game`** (`D2Game.dll`, `61` exports): Full `1.12a` server simulation, game loop (`GAME_*`), client session management (`CLIENTS_*`), packet dispatch (`SCMD_*`/`CCMD_*`), quests (`QUESTS_*` Act 1–5 + Uber Tristram), monster AI (`AI_*`), character `.d2s` save/load (`PLRSAVE_*`), and physics/combat (`SUNITDMG_*`).
5. **`source/D2Net`** (`D2Net.dll`, `38` exports): Client/server packet ring buffers, Winsock/local loopback transport, packet length framing (`NET_GetPacketFullSize`), and critical section helpers.
6. **`source/D2Lang`** (`D2Lang.dll`, `63` exports): `.tbl` string table loader (`STRTABLE_*`), locale detection (`13` locales), CRC16 verification, and `Unicode` class methods.
7. **`source/D2Gfx`** (`D2Gfx.dll`, `83` exports) & **`source/D2Gdi`** (`D2Gdi.dll`, `4` exports): Window management (`WINDOW_*`), renderer dispatch table (`D2GfxCallbacksStrc`), perspective projection (`SCALE_*`), and full 8-bit palettized `800x600`/`640x480` GDI DIBSection software renderer (`D2Gdi.dll`).
8. **`source/D2Sound`** (`D2sound.dll`, `71` exports): DirectSound sample management (`D2SoundSmpStrc`), fast UI sound cache (`D2SOUND_Fast*`), background music streamer, 2D/3D panning/attenuation, and EAX environment state.
9. **`source/D2CMP`** (`D2CMP.dll`, `107` exports): CEL/DC6 sprite decompression (`Codec`, `CelCmp`), DS1/DT1 isometric tile cache (`TileCache`, `SubTile`), palette shifts (`PalShift`), and LRU sprite cache (`SpriteCache`).
10. **`source/D2Win`** (`D2Win.dll`, `207` exports): Front-end window/message loop (`D2WinMain`), UI control hierarchy (`Button`, `EditBox`, `TextBox`, `List`, `ScrollBar`, `AccountList`, `Image`, `AnimImage`, `PopUp`, `ProgressBar`, `Smack`, `Timer`), bitmap font renderer (`D2WinFont`), and paperdoll compositor (`D2Comp`).
11. **`source/D2MCPClient`** (`D2MCPClient.dll`, `63` exports): Realm MCP client state accessors and session teardown (`D2MCPClientCloseMCP`).
12. **`source/D2Launch`** (`D2Launch.dll`, `1` export `QueryInterface @1`): Front-end state machine (`D2LAUNCH_MainEntry`), title/logo screen, main menu (`Single Player`, `Battle.net`, `Other Multiplayer`, `Exit Diablo II`), `.d2s` character enumeration and selection (`D2LAUNCH_EnterCharSelect`), new character `.d2s` (`v96`/`0x60`, `335` bytes) creation (`D2LAUNCH_InitNewSaveAndPreview`, `D2LAUNCH_WriteNewSaveFile`), and `D2ConfigStrc` handoff to `D2Client.dll`.
13. **`source/D2Client`** (`D2Client.dll`, `4` exports `#10001`–`#10003`, `QueryInterface @10004`): Client state machine (`gapfnClientStateHandlers` states `0..6`), single-player & TCP/IP local server lifecycle (`SERVER_Initialize`, `CLIENT_Initialize`, `GAME_InitGameDataTable`, `D2Game_10046`), `0x2E`-byte `0x67` (`D2GS_GAMELOGON`) join packet construction (`D2Client_SendJoinGamePacket`), background server thread (`D2Client_ServerThreadProc`), and game loop orchestration (`D2Client_RunGameLoop`).
14. **`source/Game`** (`Game.D2MOO.exe`): `WinMain` / `GameStart` executable entry point, CLI flag parser (`-w`, `-ns`, `-act`, `-seed`, `-txt`, `-direct`, `-skiptobnet`), renderer initialization, and module state loop (`MODULE_CLIENT`, `MODULE_SERVER`, `MODULE_MULTIPLAYER`, `MODULE_LAUNCHER`, `MODULE_EXPAND`).

## 4. Build & Test Verification

Configure and build all `1.12a` targets (32-bit `Win32`, `Release` or `Debug`):

```bash
cmake -S . -B build-112a -A Win32 -DD2MOO_ORDINALS_VERSION=1.12a
cmake --build build-112a --config Release
ctest --test-dir build-112a -C Release --output-on-failure
```
